03 · The solutionInput: denial + file

What OVERTURN does

Read the file.
Find the contradiction.
Answer it.

OVERTURN is an appeal agent, not a chat assistant. It reads the denial, the policy, the clinical record, the EOB, the code tables and the document checklist — then drafts an internal appeal packet a human can send.

01

Read

Nine sources, queried through one read-only tool. Policy clauses, denial reasons, records, EOB, procedure codes, document checklist, ICD-10.

10 · Unique sponsor-technology useNot logos — load-bearing

The combination

The sponsors are not
logos. They are
the argument.

01
Remove the World Model.

The Critic has no shared case to read. Re-query stops being stateful, and the agents start passing summaries instead of evidence.

02
Remove H-MEM.

Every appeal starts cold. The insurer's denial pattern is relearned on every run, and the second case costs the same as the first.

03
Remove Nightshift's Nemotron lane.

The adversary and the rebuttal collapse into one voice. Nobody is left to try to break the appeal before the insurer does.

What stays outside the model
  • 01The appeal-strength score — deterministic Python, no LLM.
  • 02The SQL guard — writes, DDL and multiple statements rejected.
  • 03The SHA-256 chain — recomputable from the emitted evidence.
  • 04The missing letter — listed as missing, never generated.

Two models argue. One deterministic referee scores. The human signs.
