# Third-party components

## VoiceStudio / OmniVoice (film narration)

The marketing film's narration is generated locally with
[VoiceStudio](https://github.com/debpalash/VoiceStudio), using its default
`k2-fsa/OmniVoice` engine.

- The OmniVoice model weights are **non-commercial** (CC-BY-NC and related
  terms; the audio tokenizer carries separate Boson AI / Meta terms).
- This repository uses the model only for a non-commercial hackathon demo and
  records the licence here. The generated narration is not licensed for
  commercial reuse.
- Do not reuse the narration in a commercial product without reviewing the
  model terms and, if necessary, replacing the voice with a permissively
  licensed engine (for example VoxCPM2 or MOSS-TTS-Nano, both Apache-2.0).
