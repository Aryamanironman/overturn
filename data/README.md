# OVERTURN synthetic sources

One claimant, one denial, one appeal: **Ava, 34, Sydney**, against the fictional
insurer **Northbridge Health**, claim **CLM-2026-0915**, procedure
**MRI-LS-001** (MRI lumbar spine without contrast).

Every file is synthetic. No real patient, insurer, provider, claim, member id
or clinical record is represented. Names, ids and domains are fictional.

## Licence and provenance

Generated by `scripts/generate_sources.py` with a fixed seed. Re-running it
reproduces the files byte for byte. The case is synthetic; you may reuse it for
the hackathon. The ICD-10-CM codes and descriptions are public (CMS); the
procedure codes, policy, records and claim are invented.

## The live ICD-10 source

The public no-key endpoint is:

```
https://clinicaltables.nlm.nih.gov/api/icd10cm/v3/search?terms=M54.5
```

It returns the public code description used to show that the denial's M51.1 is
not the record's M54.5. `data/fixtures/icd10_codes.json` is the cached response
for SAMPLE_MODE; the live registration is in
`scripts/register_zetaris_sources.sql` as two REST tables (one for each code)
plus the cached `icd10_codes` table used by the deterministic pipeline. The
cached table keeps SAMPLE_MODE reproducible; the REST tables prove live source
connectivity.

## How the sources are registered in Zetaris

`scripts/register_zetaris_sources.sql` registers:

- `policy_clauses`, `denial_reasons`, `medical_records`, `eob`,
  `procedure_codes`, `claim_documents` and `icd10_codes` as Lightning file
  tables from a bucket Zetaris can reach.
- `icd10_m545` and `icd10_m511` as live REST tables against the public ICD-10
  API.
- `appeal_evidence` — the denial-policy-code-diagnosis view.
- `claim_facts` — the deterministic maxima and missing-document count.
- Smoke queries for the four planted conflicts.

**Files on a laptop are not visible to Zetaris.** Upload `data/sources/*.csv`
to an S3-compatible bucket (AWS S3 or a local MinIO container) and set the
`PATH` and S3 endpoint in the SQL. The SQL uses `s3a://overturn/...` as the
placeholder. The exact connector options must be confirmed against the
deployed Zetaris version; the table names, columns and view semantics are
final.

## What is deliberately incomplete

- The specialist referral letter (DOC-003) is missing. It must stay missing.
- The denial's procedure code and diagnosis differ from the file.
- One bank of 12 physiotherapy sessions is real evidence; it is not a
  placeholder.
- There is no real personal data and no real insurer.
